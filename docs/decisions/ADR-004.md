# ADR-004 — Settings tab and bring-your-own-key AI assistant

Date: 2026-11-27 · Status: accepted (owner request "bổ sung tab cài đặt … nhập api ai")

## Context
Settings (sync, backup, privacy) lived inside Library. The owner asked for a dedicated Settings tab and for "smart" features
powered by an AI API key they enter themselves. The product promise is private and offline-first: nothing leaves the device unless the owner chooses.

## Decision
- Navigation gains a sixth tab, **Settings** (`/settings`): display (light/dark/system), AI assistant, sync, backup, privacy.
  Sync, backup and privacy screens moved from `/library/*` to `/settings/*`. Library keeps memories and statistics.
- AI is **off by default**, provider Anthropic Claude only, via the official `@anthropic-ai/sdk` called from the browser
  (`dangerouslyAllowBrowser`) with the owner's own key. No TravelMemo server or proxy.
- The key and the theme preference live in `localStorage` only: not in SQLite, so never in backups and never synced to Firestore.
- Every AI action shows the exact text that will be sent ("Xem dữ liệu sẽ gửi") and runs only on a tap. Sent: journey titles, dates, place names,
  province/country, notes and journal (opt-out per request), companion names (opt-in). Never sent: photos, coordinates, IDs, account data.
- AI output is a suggestion. Journal drafts go into the normal journal form and are saved only after the owner edits and confirms; AI never
  creates visits or stamps, so coverage rules are unchanged.
- Default model `claude-opus-5-5` (owner can pick Sonnet 5.5 or Haiku 5.5), adaptive thinking, effort `medium`, streaming,
  server-side refusal fallback (`fallbacks: "default"`) on Opus/Sonnet. Context is capped at 60,000 characters.

## Consequences
- Usage is billed to the owner's Anthropic account; TravelMemo has no cost and holds no secret.
- A key in browser storage can be read by anyone with access to that browser profile or by injected script; mitigations: off by default,
  masked display, one-tap delete, no third-party scripts in the app. The owner should use a key with a spending limit.
- Other providers (OpenAI, Gemini) are not included; adding one is a new provider in `src/services/ai/`.
