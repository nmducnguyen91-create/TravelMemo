# ADR-002 — Web app first (owner decision 2026-11-25)

**Decision.** Deliver TravelMemo first as a responsive web app (phone and desktop browsers), built from the same
Expo/React Native codebase via react-native-web. iOS remains possible later from the same code.

**Why.** Owner request: usable on phone and computer without App Store, Apple Developer membership or signing.

**Consequences.**
- Storage: SQLite runs in the browser as WebAssembly (sql.js). The full database image is persisted to IndexedDB after
  every committed write; media bytes are stored in IndexedDB separately from metadata. No server, no account.
- expo-sqlite / expo-file-system are not used on web. The `SqlDriver` and `MediaStore` interfaces keep repositories
  platform-independent; a native build would add expo-sqlite / file-system adapters (not yet written).
- Only one tab may open the database (Web Locks) to prevent two in-memory copies overwriting each other.
- Browsers may evict site data. Mitigations: `navigator.storage.persist()`, "Add to Home Screen" on iPhone, prominent
  backup reminders, verified export/restore with rollback.
- Location is a one-shot browser geolocation request (HTTPS or localhost only); denial falls back to manual selection.
- Offline after first load via a service worker (HTTPS or localhost only).
- Backup encryption uses the browser's WebCrypto (AES-256-GCM, PBKDF2-SHA-256 600k). Not available on plain HTTP; the
  UI then labels exports as unencrypted.
- Geography: Natural Earth 5.2.0 (public domain), Vietnam point-of-view admin-0 (includes Hoàng Sa, Trường Sa) and
  63 pre-July-2025 provinces. The 34-province set is a pending dataset version.
