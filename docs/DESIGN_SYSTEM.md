# 03 — Design system
Modern Heritage / Editorial Cartography. Premium iOS, paper atlas, collectible passport. Avoid generic admin dashboard, excessive gradients/shadows, emoji icons. SF system sans, system serif editorial titles; Vietnamese support. Display 40, large title 32, title 28/22, headline 17, body 16, caption 12. 4pt grid, padding 20, radius 8/12/16/20/28, touch target 44pt, button 52pt. Use semantic tokens in specs/design-tokens.json.
Components: AppScreen, AppHeader, SectionHeader, JourneyCard, PlaceCard, MemoryCard, StampCard, PassportCover, PassportPage, AtlasCanvas, MapMarker, RoutePolyline, StatCard, TimelineItem, PhotoGrid, FilterChip, BottomSheet, EmptyState, Skeleton, ErrorState, PermissionCard, ConfirmDialog.
Atlas: neutral unexplored, forest visited, distinct outline selected; accessible legend, attribution, no color-only meaning. Passport: paper texture subtle, SVG motifs, date and place legible, normalized layout. Motion: stamp 450ms, page 350ms, sheet 250–350ms; reduce motion alternative. Light/dark, VoiceOver, Dynamic Type, one-hand operation. No fake production data.
