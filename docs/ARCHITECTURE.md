# 06 — Architecture
React Native/Expo/TypeScript, Expo Router, SQLite, Zustand, Zod, SVG, Expo Image, Location, FileSystem; native maps optional for Journey Map. No backend MVP. Presentation → application → domain; data/infrastructure implement domain contracts. app/ routes; src/core/{domain,application,contracts}; src/features; src/engines; src/database/{migrations,repositories,queries}; src/services; src/design-system; assets/geography; tests.
Atlas pipeline: licensed GeoJSON → versioned geometry → projection → SVG paths → confirmed visit coverage → renderer. Native journey map is separate, offline tiles not guaranteed. Verify Vietnam boundary sources and licensing before shipping; no invented geography.
Passport: visit confirmation transaction → idempotent stamp generation → template snapshot → normalized page rendering. Media: stage copy → hash → metadata transaction → cleanup on failure. Backup: consistent snapshot → manifest/checksums → archive → validate → stage restore → atomic/recoverable swap. No raw live SQLite copy. Secrets in secure storage; optional AI adapter later, explicit consent. Performance targets cold start 2.5s, local search 200ms, atlas 1s on target device; measure, not assume.
